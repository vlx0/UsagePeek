# UsagePeek

**Сколько уже сожрали твои ИИ.** Один экран: токены, сессии и локальные модели — всё читается с диска этого ПК.

**Автор:** darkshade ([@vlx0](https://github.com/vlx0))

**365 дней open source** · **неделя 7 — «ИИ»** · день 46.

---

## Возможности

- **Cursor** — сессии, % контекста, строки правок
- **MiniMax Code** — in / out / cache и стоимость из локальной SQLite
- **Claude Code**, **Codex**, **OpenCode**, **Copilot** — usage из их папок, если установлены
- **Ollama** и **LM Studio** — модели, занятое место, запущен ли локальный сервер
- **Своя локальная ИИ** — кнопка «Добавить локальную ИИ…», указываешь папку (Jan, GPT4All, llama.cpp…),
  UsagePeek сам находит файлы моделей, SQLite с токенами и jsonl-логи
- Периоды: сегодня / 7 дней / всё

Данные берутся только из файлов на этом ПК. В интернет ничего не уходит, единственное обращение к сети —
проверка локального порта (`127.0.0.1:11434`, `127.0.0.1:1234`), запущен ли движок. Секреты и тексты чатов не показываются.

## Установка

```powershell
git clone https://github.com/vlx0/UsagePeek.git
cd UsagePeek
pythonw run_usagepeek.pyw
```

Или `start.bat`.

Нужен Windows 10+ и Python 3.10+. Внешних зависимостей нет.
